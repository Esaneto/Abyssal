# Músicas do Abyssal

Coloque nesta pasta as faixas de música do jogo, mantendo os nomes originais que identificam sua finalidade (menu, mergulho, combate, boss, etc.).

Formatos recomendados: OGG ou MP3. WAV também pode ser usado, mas costuma ocupar mais espaço.

Os arquivos desta pasta serão mapeados ao sistema de áudio em uma atualização posterior. A inclusão de uma faixa não altera automaticamente o áudio atual.
