# Efeitos sonoros do Abyssal

Coloque nesta pasta os efeitos sonoros, mantendo os nomes originais que descrevem sua função (disparos, habilidades, criaturas, submarino, interface, etc.).

Formatos recomendados: OGG, MP3 ou WAV. Evite arquivos excessivamente longos para efeitos curtos.

Os arquivos desta pasta serão associados aos eventos do jogo em uma atualização posterior. A inclusão de um efeito não altera automaticamente o áudio atual.
