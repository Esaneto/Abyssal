# Security Policy

Abyssal treats the browser and mobile client as untrusted. Account data, production credentials, payments, rewards and persistent entitlements are validated by server-side systems.

Do not commit production credentials, private player data, signing material or environment files.

## Reporting

Repository security posture last verified after public release.

Please report security vulnerabilities privately to abyssalelectrongames@gmail.com. Do not publish credentials, private player information or active exploitation details in a public issue.
